# Credit Risk Telegram Bot

Проект по оценке кредитного скоринга клиентов на основе датасета Home Credit Default Risk, взятого на kaggle.

В проекте реализованы:
- EDA и обучение ML моделей;
- Сравнение этих моделей по метрикам;
- финальная CatBoost модель;
- Telegram бот для оценки риска дефолта;
- поддержка JSON ввода для одного клиента;
- поддержка CSV файлов для предсказания сразу для множества людей.
